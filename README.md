# 👋 About Me

I'm **Soumyaranjan Sahoo**, an AI Engineer and software builder interested in the intersection of **AI, software systems, research, and products**.

My journey started with learning programming, solving problems, experimenting with technologies, and building small academic projects.

Over time, that evolved into building **real applications, developer tools, Android products, web platforms, hackathon projects, and open-source software**.

Today, my work is increasingly focused on **AI systems, machine learning, agentic software, memory, developer infrastructure, system design, and research-oriented engineering**.

This profile is organized to reflect that progression:

> **Learn → Build → Engineer → Research → Ship**

I don't see these as separate stages. Each one feeds the next.
